# Titanic Survival Prediction

A machine learning project based on the Titanic dataset.

## Project Overview

The goal of this project is to predict whether a passenger survived the Titanic disaster using machine learning.

## Technologies Used

* Python
* NumPy
* pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Machine Learning Model

The project uses **Logistic Regression** for survival prediction.

## Project Steps

1. Load the Titanic dataset
2. Understand the data
3. Perform exploratory data analysis
4. Handle missing values
5. Handle outliers
6. Select useful features
7. Encode categorical features
8. Scale numerical features
9. Split the data into training and validation sets
10. Train the Logistic Regression model
11. Evaluate the model
12. Generate predictions for the Kaggle test dataset

## Files

* `Titanic_Project_1.ipynb` — Complete project notebook
* `train.csv` — Training dataset
* `test.csv` — Test dataset
* `gender_submission.csv` — Kaggle sample submission
